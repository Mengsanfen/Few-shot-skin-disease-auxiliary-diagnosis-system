# SFEPT 皮肤病图像分类论文分析与写作口径

参考论文：Yuxiang Wang, Jinrong He, Shuai Ma. Semantic-enhanced few-shot learning for precise dermatological diagnosis. The Visual Computer, 2026, 42:243. DOI: 10.1007/s00371-026-04440-y.

> 本文档用于指导毕业论文中“皮肤病图像分类算法”部分的写作。结论基于参考 PDF 与当前 Django 系统代码对照分析，原则是只写系统实际用到的功能，不把未接入系统的训练流程、实验结论或完整论文模块写成项目实现。

## 1. 论文方法概述

该论文提出 Semantic Feature Enhanced Prototypical Transformer（SFEPT），面向少样本皮肤病图像分类。论文指出皮肤病图像分类存在类间差异细微、类内变化大、标注样本稀缺、长尾类别明显等问题，传统深度学习方法对大量标注样本依赖较强，而少样本学习能够在有限支持样本下完成新类别识别。

SFEPT 的完整框架主要包含四个部分：

1. Swin Transformer 特征提取器，用于提取皮肤图像层次化视觉特征。
2. 原型网络分类思想，通过支持集样本特征均值构建类别原型。
3. Prototype Rectification / Bias Diminishing，用于缓解少样本支持集导致的原型偏移。
4. Semantic-Aware Enhancement（SAE），通过冻结 BERT 将视觉特征投影到潜在语义空间，增强语义表达。

论文还包括训练过程、测试过程、三个皮肤病数据集实验、对比实验和消融实验。

## 3. 论文中推荐的准确表述

### 3.1 可写表述

以下表述与当前系统代码一致：

- 本系统的皮肤病图像分类模块借鉴 SFEPT 的少样本原型分类思想，采用 Swin Transformer 提取图像特征，并基于支持集特征构建类别原型。
- 系统在推理阶段通过支持集样本计算类别原型，对查询图像提取特征后进行原型修正，最后依据查询特征与类别原型之间的距离完成分类。
- 为减弱少样本支持集与查询图像之间的分布差异，系统实现了 Bias Diminishing 思路下的特征偏移校正与原型更新。
- 系统将皮肤图像统一预处理为固定尺寸，并进行张量化和归一化，以适配 Swin Transformer 的输入要求。
- 系统以单例模式加载模型权重和支持集特征，避免每次请求重复初始化模型，提高 Web 推理服务的稳定性。
- 系统支持 CPU 与 CUDA 设备切换，便于在不同部署环境中运行。

## 5. 可放入论文的公式

### 5.1 类别原型计算

设第 \(n\) 类支持集样本为 \(x^{(n)}_j\)，特征提取器为 \(f_\theta(\cdot)\)，每类有 \(K\) 个支持样本，则类别原型可表示为：

$$
c_n=\frac{1}{K}\sum_{j=1}^{K}f_\theta(x^{(n)}_j)
$$

该公式对应当前系统中的 `compute_prototypes()`。

### 5.2 查询特征偏移校正

设支持集特征均值为 \(\mu_S\)，查询集特征均值为 \(\mu_Q\)，查询特征为 \(F_q\)，则偏移校正后的查询特征为：

$$
F'_q = F_q + (\mu_S - \mu_Q)
$$

该思想对应当前系统 `rectify_prototypes()` 中的 `average_support_query_shift`。

### 5.3 类别预测

系统最终使用查询特征与类别原型之间的距离进行分类，可表示为：

$$
\hat{y}=\arg\max_{n} \; \text{Softmax}(-d(F_q,c_n))
$$

其中 \(d(\cdot)\) 在当前系统中主要通过 `torch.cdist` 计算 L2 距离。
